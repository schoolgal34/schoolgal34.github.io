## Professional Self-Assessment

My journey through the Computer Science program has been a steady climb from simply “getting code to run” to understanding how real systems behave, how data moves, and how security fits into every decision. I started this program in Spring 2023, and over time I’ve learned how the front end, back end, and database layers actually talk to each other. I’ve learned how to evaluate algorithms instead of guessing, and how to design databases that protect the information they hold. Building my ePortfolio forced me to look at my work the way an employer would: not just as assignments, but as proof of how I think, how I solve problems, and how I grow.

Throughout the program, I’ve worked in team environments, communicated with instructors and peers, and learned how to explain my decisions clearly. I’ve practiced algorithmic reasoning through benchmarking and complexity notes, strengthened my software engineering skills through refactoring and defensive programming, and built confidence in database design by improving structure, indexing, and security. I also learned how important a security mindset is—small choices like removing hardcoded credentials or validating input can make the difference between a safe system and a vulnerable one.

The three artifacts in my ePortfolio fit together like a full‑stack story. The software engineering artifact shows how I can take messy code and turn it into something structured and secure. The algorithms artifact shows how I think about efficiency and logic. The database artifact shows how I handle data responsibly and professionally. Together, they demonstrate all five course outcomes and show the kind of developer I’m becoming: someone who cares about clarity, performance, and security. This portfolio is more than a graduation requirement—it’s the first version of the professional identity I’ll carry into my career as a database administrator.
